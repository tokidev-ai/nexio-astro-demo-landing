Rules

  • Language is a two-state toggle with aria-pressed, never a select. It swaps the route (/ ↔ /en/) and preserves scroll position.
  • The open mobile sheet traps focus and closes on Escape.
  • The nav CTA is the one exception to "one gold button per viewport" — it is chrome, not content, and never appears in the same band as a section CTA.
  • The underline grows via transform: scaleX, never width.
